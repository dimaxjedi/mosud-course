# lab02. Множества и мультимножества. Нидзий Д.В. ИНБО-21-23, Вариант 10

A - товары из MA (delivered), B - товары из PI (delivered).

множество | значение 
A, строк | 800 
A, distinct product_id | 657 
B, строк | 523 
B, distinct product_id | 446 
A ∪ B (union) | 1046
A ∪ B (union all) | 1323 
A ∩ B (intersect) | 7
A − B | 60
B − A | 38
A ∪ B == B ∪ A | да, 1046 == 10
A ∩ B == B ∩ A | да, 57 == 5
A ∩ B через exists | 57 
симметрическая разность | 989 

# Выводы

1. запросы A и B построены, для каждого посчитаны count(*) и count(distinct product_id). у A: 800 строк и 657 уникальных товаров, у B: 523 строки и 446 уникальных. count(*) больше count(distinct), значит внутри одного штата один и тот же товар покупали несколько раз.

2. A ∪ B через union дал 1046, через union all дал 1323. union убирает дубликаты и возвращает множество, union all оставляет все строки (мультимножество). разница 1323 − 1046 = 277 это дубликаты, которые union all сохранил, а union удалил. 1323 также равно 800 + 523, то есть union all просто склеил оба результата.

3. A ∩ B через intersect дал 57. это товары, которые покупали и в MA, и в PI одновременно.

4. A − B = 600 (товары из MA, которых нет в PI), B − A = 389 (товары из PI, которых нет в MA). числа разные, значит разность зависит от порядка.

5. коммутативность проверена: A ∪ B = B ∪ A = 1046, A ∩ B = B ∩ A = 57. объединение и пересечение коммутативны на этих данных.

6. разность некоммутативна: A − B = 600, B − A = 389, числа не равны. симметрическая разность (A − B) ∪ (B − A) = 989, она непустая, что подтверждает некоммутативность.

7. пересечение переписано без intersect через exists, результат 57, совпадает с intersect. значит реализация верна.

8. для результата намеренно убрали union/distinct и сгруппировали по product_id. в MA нашлись товары, которые встречаются до 8 раз (например 389d119b48cf3043d311335e499d9c6b и bb50f2e236e5eea0100680137654686c), это и есть дубликаты, которые убирает union/distinct.

9. union, intersect, except без all возвращают множество (дубликаты убираются). union all, intersect all, except all и обычный select без distinct возвращают мультимножество (дубликаты остаются).

проверка по формуле включения-исключения: 657 + 446 − 57 = 1046, совпадает с union.
