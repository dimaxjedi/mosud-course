# lab05  Нидзий Д.В. ИНБО-21-23, Вариант 10

множество s: AL, SE, BA.

1. Создать cte target_states из трёх значений своего варианта.
создано cte target_states(state) со значениями AL, SE, BA. select вернул 3 строки.

2. Реализовать условие "категория продавалась во всех штатах s" через двойной not exists.
получилось 35 категорий. логика: для каждого кандидата проверяем, что не существует штата из target_states, для которого не существует доставленного заказа с товаром этой категории. то есть "не существует штата, где категории нет".

3. Реализовать то же через group by / having count(distinct customer_state).
тоже 35 категорий. группируем доставленные заказы по категории, фильтруем только штаты из target_states, требуем count(distinct customer_state) = мощность делителя (3). совпадает с результатом двойного not exists.

4. Реализовать то же через except и not exists.
тоже 35 категорий. строим candidates (все категории products, не null) и covered (какие штаты из s категория реально покрывает). затем not exists от target_states — то же самое, что двойной not exists, только через отдельную cte.

5. Сравнить множества результатов оператором except в обе стороны.
r1 (двойной not exists) минус r2 (group by/having) = 0 строк. r2 минус r1 = 0 строк. значит все три реализации эквивалентны на данных.

6. Для одной найденной категории вывести диагностическую таблицу: категория -> штат -> число заказов.
взял первую категорию из результата: alimentos. распределение заказов по штатам: AL = 1, BA = 14, SE = 1. категория реально покрывает все три штата из s.

7. Проверить поведение решения при пустом target_states. коротко объяснить результат с точки зрения логики.
при пустом target_states двойной not exists возвращает все категории: условие "для всех штатов из пустого множества p(x) истинно" выполняется вакуумно. проверка вернула 10 первых категорий (ограничение limit 10 на полном списке из 35). то есть логика реляционного деления корректно работает на пустом делителе: результат — все делимое.

8. Дополнительно: найти продавцов, которые продавали товары покупателям каждого из трёх штатов.
через ту же логику двойного not exists, но по seller_id. вернулось 20+ продавцов (в выводе limit 20), значит есть продавцы, покрывающие все три штата из s.
