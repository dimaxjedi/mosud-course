# lab11. Представления, CTE и рекурсивные запросы. Нидзий Д.В. ИНБО-21-23, Вариант 10

Корневой штат для рекурсии: GO.

1. Обычное представление v_order_summary
Создано lab.v_order_summary: одна строка на заказ. Поля: order_id, customer_state, items_count (число позиций), total_sum (сумма price + freight). Проверка вернула первые 10 строк, например заказ 00010242... из RJ с суммой 72.19.

2. Материализованное представление mv_monthly_state_sales
Создано lab.mv_monthly_state_sales: месяц, штат, число заказов, сумма. REFRESH-команда:
refresh materialized view lab.mv_monthly_state_sales;
Материализованное представление хранит результат физически и требует refresh при обновлении данных, в отличие от обычного view, которое выполняется каждый раз.
Выборка вернула 556 строк.

3. Сложный аналитический запрос на трёх CTE
Задача: по каждому штату за последние 12 месяцев показать долю заказов с отзывом 5 звёзд и среднюю сумму заказа, оставить только штаты, где доля 5 звёзд выше средней.
CTE:
last_month — последняя дата покупки в orders.
sales — суммы заказов delivered за последние 12 месяцев по штатам.
reviews — признак is_5: был ли у заказа отзыв с оценкой 5.
agg — агрегаты по штатам: число заказов, средняя сумма, доля 5 звёзд.
Финальный select фильтрует штаты с долей выше средней. В топ попали SP (0.614), PR (0.601), MG (0.591), MT (0.590), AM (0.589) и другие.

4. lab.geo_tree
Создана таблица lab.geo_tree с полями node_id, parent_id, node_type (country/state/city), node_name.
Иерархия: BR → штат → город. Для каждого штата — до 20 городов с наибольшим числом клиентов (row_number over partition by state order by count desc).
Итого 495 узлов: 1 страна, 27 штатов, 467 городов.

5. Рекурсивный запрос на поддерево от ST:GO
Базовая часть: select узла ST:GO с depth=0 и path=node_id.
Рекурсивная часть: join lab.geo_tree с subtree по parent_id = node_id, depth+1, path склеивается через ' > '.
Результат: 21 узел — ST:GO и 20 городов GO. Пример path: ST:GO > CT:GO:goiania.

6. Обратный рекурсивный запрос для CT:GO:goiania
Базовая часть: узел CT:GO:goiania с level=0.
Рекурсивная часть: join предков через parent_id.
Цепочка предков: CT:GO:goiania (level 0) → ST:GO (level 1) → BR (level 2).
Пример path: CT:GO:goiania > ST:GO > BR.

7. Количество потомков каждого state-node
Через рекурсивный CTE sub: стартуем от всех узлов с node_type = 'state', разворачиваем поддерево, потом group by root, count(*) - 1 (минус сам штат).
Для каждого штата получилось 20 потомков — по числу городов, включённых в дерево (не больше 20 по правилу).
Топ-10 штатов с 20 потомками: SE, RN, BA, GO, CE, SC, TO, PA, RS, PE.

8. Защита рекурсии от цикла
Если в дереве появится цикл (например, a → b → a), рекурсия без ограничения уйдёт в бесконечность. Способы защиты:
- Ограничение по глубине: where s.depth < N в рекурсивной части.
- Встроенный cycle в PostgreSQL 14+: ... cycle node_id set is_cycle using path — судб сама отслеживает, что узел уже встречался, и останавливает рекурсию.
В примере использовано ограничение depth < 5. Запрос вернул 21 узел.

Итог
View и MV, три именованных CTE, рекурсивный обход дерева вниз и вверх, подсчёт потомков, защита от циклов — все пункты выполнены.
